## Issue Description
Ensure buttons have discernible text

## Affected Element
Selector: `.ai-newsletter-banner__submit-`

## User Impact
Screen reader users cannot understand the button's purpose, making it impossible to interact with the newsletter subscription feature. Keyboard-only users also lack context for what action the button performs.

## BFSG/Legal Risk
Violates WCAG 4.1.2 (Name, Role, Value) and BFSG accessibility requirements, exposing the organization to legal liability and potential discrimination claims.

## AI-Suggested Fix

### Before
```html
<button class="ai-newsletter-banner__submit-"></button>
```

### After
```html
<button class="ai-newsletter-banner__submit-" aria-label="Subscribe to newsletter">Subscribe</button>
```

**Fix type:** button-text|aria-label
**Confidence:** 95%

## Manual Test Steps
1. Enable a screen reader (NVDA, JAWS, or VoiceOver). 2. Navigate to the button using Tab key. 3. Verify the screen reader announces 'Subscribe to newsletter, button' or similar. 4. Ensure visible text is readable on the button visually. 5. Verify keyboard activation works (Enter/Space key).
