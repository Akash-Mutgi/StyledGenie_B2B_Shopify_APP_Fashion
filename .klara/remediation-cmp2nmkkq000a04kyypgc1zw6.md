## Issue Description
Ensure <img> elements have alternative text or a role of none or presentation

## Affected Element
Selector: `.banner-hero__image--desktop`

## User Impact
Screen reader users cannot understand the purpose or content of the banner hero image, missing critical visual information. Decorative images without proper markup create confusion and reduce navigation efficiency.

## BFSG/Legal Risk
WCAG 1.1.1 Level A violation exposes the organization to accessibility compliance failures and potential legal liability under disability access laws.

## AI-Suggested Fix

### Before
```html
<img class="banner-hero__image--desktop" src="banner.jpg">
```

### After
```html
<img class="banner-hero__image--desktop" src="banner.jpg" alt="Descriptive text of banner content">
```

**Fix type:** alt
**Confidence:** 95%

1. Disable images in browser dev tools. 2. Run axe DevTools or WAVE. 3. Test with screen reader (NVDA/JAWS) to confirm text is announced. 4. Verify alt text is concise and describes the image purpose/content.
