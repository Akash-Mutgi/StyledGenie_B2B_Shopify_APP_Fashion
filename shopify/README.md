# Shopify Integration Notes

This folder contains the first placeholder files for the storefront widget as a Shopify theme app extension.

## Why This Exists

The storefront assistant needs to appear inside a Shopify theme.

For the MVP, the simplest path is:

1. build the widget UI
2. expose backend endpoints
3. embed the widget through a theme app extension or app embed

## What To Do Later

- Create the real Shopify app using Shopify CLI.
- Move the placeholder widget files into the generated extension structure if needed.
- Add store authentication.
- Load merchant-specific settings into the widget.
- Send chat messages from the storefront to your backend.
