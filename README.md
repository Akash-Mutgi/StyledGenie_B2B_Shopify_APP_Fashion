# StyledGenie B2B Intelligence System MVP

This repository has been rebuilt from scratch as a cleaner starting point for the StyledGenie MVP.

The focus of this version is:

- a simple storefront AI chat widget
- a simple merchant dashboard demo
- a Python backend skeleton for AI and catalog logic
- a Supabase starter schema
- a beginner-friendly build plan for someone with no coding experience

## Project Structure

- `apps/storefront-widget/` - standalone demo of the customer-facing AI widget
- `apps/merchant-dashboard/` - standalone demo of the merchant dashboard
- `backend/` - FastAPI starter for chat, analytics, support, and catalog endpoints
- `supabase/` - starter database schema
- `shopify/` - starter theme app extension placeholder files
- `docs/` - plain-English project plan and build steps
- `langflow/` - placeholder notes for future visual AI orchestration

## What Is Already Included

- a working folder structure
- HTML/CSS/JavaScript demo screens for the storefront and dashboard
- backend API files with mock responses
- SQL tables for products, looks, FAQs, chat, and analytics
- a manual QA checklist

## What Is Not Done Yet

- real Shopify authentication
- real Supabase queries
- real OpenAI responses
- real Google Vision image analysis
- real LangChain or Langflow orchestration

This is a clean MVP starter, not a finished production app.

## Suggested First Goal

Get the backend running locally, open the two HTML demo screens, then replace one mock endpoint at a time with real data.
